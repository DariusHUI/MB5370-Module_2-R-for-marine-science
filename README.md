This reporitory is for codes and other work relating to the second module (R for Marine Science) of subject MB5370 Techniques in Marine Science 1 taught at JCU.

The module is devided into 4 different workshops as described below:
  - Workshop 1 - Foundations of Data Science - Wrangling and Plotting
  - Workshop 2 - Advanced data wrangling: Extracting ecological signals from noisy systems
  - Workshop 3 - Advanced Data Communication & Open-Ended Sourcing
  - Workshop 4 - Spatial Engineering & Reproducible Reporting
  
  * note that the 3rd and 4th workshops haven't been conducted as planned, which is why no work is present in this repository for Workshop 3 and the work for Workshop 4 in not compete
  
  This repository is devided into different parts as follow:
    - code
      - Workshop1.R 
          contains a first part of the first workshop realised before switching to a qmd script (Workshop1.qmd)
      - Workshop1.qmd 
          contains all the work conducted during the first workshop (including the content of Workshop1.R)
      - Workshop2.qmd 
          contains all the work conducted during the second workshop (excluding the content related to exercise 12)
      - Workshop2_Ex12.qmd 
          contains the work done to complete the 12th exercise of the second workshop
      - Workshop4.qmd 
          contains uncompleted work related to the forth workshop
      - outputs
          - figures
              contains generated figures
          - tables
              contains generated tables
      - Rdata (empty)
      
    - data
      - workshop1
          contains the data used for the first workshop
      - workshop2
          contains the data used for the second workshop
      - workshop4
          contains the data used for the third workshop
